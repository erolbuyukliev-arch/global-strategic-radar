# GLOBAL STRATEGIC RADAR

MVP v0.1 built with Python + Streamlit.

## Current state
- Global strategic dashboard
- Strategic hotspots
- Domain scores
- China–Taiwan assessment
- Competing hypotheses
- Early-warning indicators
- Demo/seed data only

## Deploy on Streamlit Community Cloud
1. Create a GitHub repository named `global-strategic-radar`.
2. Upload all files in this repository.
3. Go to https://share.streamlit.io/
4. Sign in with GitHub and connect the repository.
5. Create an app using `app.py` on the `main` branch.
6. Deploy.
